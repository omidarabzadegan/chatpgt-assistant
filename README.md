# دستیار چت جی پی تی

**توسعه یافته توسط امید عرب زادگان** · تماس: **09128848707**

افزونه محلی Chrome برای اتصال امن `chatgpt.com` به پروژه‌های روی ویندوز است. این ابزار کمک می‌کند ChatGPT بتواند با اجازه شما ساختار پروژه را بخواند، فایل بسازد، فایل‌ها را ویرایش کند، تست اجرا کند و نتیجه عملیات را دوباره به همان گفتگو برگرداند.

این پروژه API خارجی، سرور عمومی یا پورت localhost لازم ندارد و از Native Messaging خود Chrome برای ارتباط بین افزونه و برنامه محلی استفاده می‌کند.

## قابلیت‌ها

- انتخاب یک یا چند پروژه محلی از داخل popup افزونه
- خواندن درخت پروژه و جست‌وجو در فایل‌ها
- ساخت هم‌زمان فایل‌ها و پوشه‌ها با دستور `write_files`
- ویرایش فایل‌های موجود با Unified Git Patch
- اجرای تست‌ها و دستورهای محلی فقط از روی allowlist
- تاریخچهٔ مستقل از Git با بازگردانی چندمرحله‌ای، نمایش فایل‌ها و حجم، و پاک‌سازی
- روشن/خاموش کردن دسترسی افزونه به پروژه فعال
- مدیریت دسترسی جداگانه برای Console محلی و اتصال SSH
- تعریف پروفایل سرور و اتصال SSH بدون ارسال محتوای کلید خصوصی به ChatGPT

## از چه چیزهایی استفاده شده است؟

- **Chrome Extension Manifest V3** برای ساخت افزونه مرورگر
- **JavaScript** برای popup، content script و background service worker
- **Chrome Native Messaging** برای ارتباط امن بین افزونه و برنامه ویندوزی
- **C# / .NET Framework** برای برنامه محلی `ProjectBridge`
- **PowerShell** برای نصب، حذف نصب و اجرای تست‌ها
- **Git Patch** برای اعمال تغییرات کنترل‌شده روی فایل‌ها
- **Chrome Storage** برای نگهداری تنظیمات افزونه مثل پروژه فعال و وضعیت دسترسی‌ها
- **SSH** برای اجرای عملیات کنترل‌شده روی سرور، فقط در صورت فعال‌سازی و تعریف پروفایل امن

## ساختار پروژه

- `extension/`: کد افزونه Chrome، شامل popup، background و content script
- `native/ProjectBridge.cs`: برنامه محلی Native Host برای خواندن، نوشتن، تست و عملیات امن روی پروژه
- `native/com.chatgpt_assistant.project_bridge.json`: manifest اتصال Native Messaging
- `scripts/install.ps1`: کامپایل Native Host، ثبت آن در ویندوز و ساخت shortcut مرورگر
- `scripts/uninstall.ps1`: حذف ثبت Native Host و shortcutها
- `scripts/test.ps1`: تست یکپارچه روی fixture مستقل
- `tests/`: تست‌های جاوااسکریپت و فایل‌های کمکی تست

## نصب

اگر بسته ZIP را دریافت کرده‌اید، ابتدا آن را **Extract All** کنید، پوشهٔ `chatgpt-assistant` را در یک مسیر ثابت نگه دارید، PowerShell را در همان پوشه باز کنید و از مرحلهٔ ۲ ادامه دهید. برای نصب نسخهٔ ZIP نیازی به Git نیست. پوشهٔ افزونه را بعد از نصب جابه‌جا نکنید.

1. پروژه را از GitHub دریافت کنید:

```powershell
git clone https://github.com/omidarabzadegan/chatpgt-assistant.git
cd chatpgt-assistant
```

2. نصب‌کننده را اجرا کنید:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1 -SkipLaunch
```

3. وارد Chrome شوید و صفحه زیر را باز کنید:

```text
chrome://extensions
```

4. گزینه **Developer mode** را روشن کنید.

5. اگر افزونه خودکار باز نشد، روی **Load unpacked** بزنید و پوشه `extension/` همین پروژه را انتخاب کنید.

6. بعد از نصب یا تغییر فایل‌های افزونه، از همان صفحه `chrome://extensions` روی **Reload** بزنید.

7. به `https://chatgpt.com` بروید و افزونه را از نوار ابزار Chrome باز کنید.

8. با دکمه `+` پوشه پروژه‌ای را که می‌خواهید ChatGPT روی آن کار کند انتخاب کنید.

## نصب با پروفایل دیگر Chrome

نصب‌کننده به‌صورت پیش‌فرض از پروفایل `Default` استفاده می‌کند. اگر افزونه را در پروفایل دیگری می‌خواهید، نام پروفایل را بدهید:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1 -ChromeProfile "Profile 7" -SkipLaunch
```

## تست

برای اجرای تست‌های پروژه:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\test.ps1
```

این تست‌ها روی fixture جداگانه اجرا می‌شوند و نباید پروژه واقعی شما را تغییر بدهند.

## استفاده

1. افزونه را در صفحه ChatGPT فعال نگه دارید.
2. از popup افزونه پروژه فعال را انتخاب کنید.
3. درخواست خود را در ChatGPT بنویسید؛ برای مثال:

```text
داخل این پروژه یک صفحه HTML ساده بساز و فایل‌های CSS و JS آن را جدا کن.
```

4. افزونه در صورت نیاز زمینه پروژه را جمع‌آوری می‌کند.
5. ChatGPT عملیات لازم را در قالب دستورهای Bridge تولید می‌کند.
6. Native Host عملیات را اجرا می‌کند و نتیجه به گفتگو برمی‌گردد.

## تنظیمات امنیتی

- دسترسی اصلی افزونه با سوییچ popup روشن یا خاموش می‌شود.
- دسترسی Console محلی جداگانه خاموش/روشن می‌شود و پیش‌فرض آن خاموش است.
- اتصال SSH جداگانه خاموش/روشن می‌شود و پیش‌فرض آن خاموش است.
- مسیرهای حساس مثل `.env`، `.ssh`، credential، secret و dependency folderها مسدود هستند.
- فایل‌های اجرایی، مسیرهای مطلق و path traversal پذیرفته نمی‌شوند.
- دستورهای محلی و سروری فقط وقتی اجرا می‌شوند که در allowlist باشند.
- محتوای کلید خصوصی SSH به ChatGPT ارسال نمی‌شود.

## پروفایل SSH

برای اتصال به سرور باید یک پروفایل امن تعریف شود. نمونه ساختار تنظیمات:

```json
{
  "id": "production",
  "host": "example.com",
  "user": "deploy",
  "port": 22,
  "identityFile": "C:\\Users\\you\\.ssh\\id_ed25519",
  "workingDirectory": "/var/www/app",
  "allowedCommands": ["git status", "git pull", "php artisan", "npm run"]
}
```

فقط دستورهایی که در `allowedCommands` آمده‌اند قابل اجرا هستند. وقتی به SSH نیاز ندارید، دسترسی آن را از popup خاموش نگه دارید.

## حذف نصب

برای حذف ثبت Native Host و shortcutها:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\uninstall.ps1
```

این دستور فقط ثبت سیستمی و shortcutها را حذف می‌کند. حذف کامل فایل‌های پروژه باید جداگانه و با تصمیم خودتان انجام شود.

## خطاهای رایج

### خطای `Specified native messaging host not found.`

یعنی Native Host ثبت نشده یا مسیر پروژه بعد از نصب جابه‌جا شده است. دوباره نصب‌کننده را اجرا کنید:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1 -SkipLaunch
```

سپس افزونه را از `chrome://extensions` دوباره Reload کنید.

### افزونه پاسخ نمی‌دهد

- مطمئن شوید داخل `https://chatgpt.com` هستید.
- افزونه را Reload کنید.
- سوییچ اصلی افزونه را روشن کنید.
- اگر پروژه را جابه‌جا کرده‌اید، دوباره `install.ps1` را اجرا کنید.

## تاریخچه و بازگردانی (نسخه ۱.۷)

در پنجره افزونه، بخش **تاریخچه پروژه** مراحل پروژه فعال را از جدید به قدیم نشان می‌دهد. پیش از هر عملیات `write_files` یا `apply_patch` نسخهٔ فایل‌های درگیر ذخیره می‌شود؛ بازگردانی نیازی به نصب Git، مخزن یا حساب GitHub ندارد. خود قابلیت اعمال Git Patch همچنان به ابزار Git نیاز دارد.

1. پروژه را انتخاب کنید و از ChatGPT بخواهید فایل‌ها را بسازد یا ویرایش کند.
2. پنجره افزونه را باز کنید یا **تازه‌سازی** را بزنید.
3. با باز کردن جزئیات مرحله، مسیر فایل‌ها را ببینید.
4. **بازگردانی یک مرحله** یا **بازگشت چند مرحله** را انتخاب و تأیید کنید. تمام تغییرات ذخیره‌شده از جدیدترین مرحله تا مرحله انتخابی برگردانده می‌شوند؛ مراحل مصرف‌شده حذف می‌شوند. فایل‌های ایجادشده در آن مراحل نیز حذف خواهند شد.
5. **پاک کردن تاریخچه** فقط نسخه‌های پشتیبان پروژه فعال را حذف می‌کند و فایل‌های فعلی پروژه را تغییر نمی‌دهد.

در ۱۰ مرحله پیام «برای عملکرد بهتر تاریخچه را خالی کنید» نمایش داده می‌شود. سقف ذخیره برای هر پروژه ۵۰ مرحله یا ۲۰۰ مگابایت نسخهٔ پشتیبان است؛ پس از رسیدن به سقف، ساخت/ویرایش بعدی تا پاک‌سازی متوقف می‌شود. هیچ مرحله‌ای مخفیانه حذف نمی‌شود.

تاریخچهٔ پروژه‌ها جداست و بعد از بستن مرورگر باقی می‌ماند. این تاریخچه مربوط به **تغییرات فایل محلی توسط افزونه** است؛ متن چت، ویرایش‌های مستقل در برنامه‌های دیگر، فرمان‌های Console، تست‌ها و تغییرات SSH را نسخه‌بندی نمی‌کند. بازگردانی، ویرایش دستی بعدی روی همان فایل‌های درگیر را نیز جایگزین می‌کند. نسخه‌های قدیمی فاقد مشخصات مسیر پروژه در فهرست جدید نمایش داده نمی‌شوند.

## اشتراک‌گذاری بدون اطلاعات شخصی

برای ساخت نسخهٔ قابل ارسال:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\package.ps1
```

فایل `release/chatgpt-assistant-1.7.0.zip` را ارسال کنید. این بسته فقط کد، آیکون‌ها، راهنما و اسکریپت‌ها را از فهرست مشخص می‌گیرد؛ تنظیمات محلی، پروژه‌های شما، تاریخچه، کلید SSH، فایل‌های باینری و پوشه `.git` وارد آن نمی‌شوند. نصب‌کننده روی دستگاه گیرنده تنظیمات تازه و یک پوشهٔ اولیهٔ خالی می‌سازد؛ تنظیمات نصب قبلی را حفظ می‌کند.

همچنین می‌توان از **Code → Download ZIP** در [همین مخزن GitHub](https://github.com/omidarabzadegan/chatpgt-assistant) استفاده کرد. پوشهٔ کاری یا پروفایل Chrome خودتان را برای دیگران نفرستید. فایل `manifest.json` افزونه دارای کلید **عمومی** برای ثابت نگه داشتن شناسهٔ افزونه است؛ این کلید خصوصی یا رمز حساب نیست.

شماره تماس سازنده عمداً عمومی است. تنظیمات واقعی پروژه‌ها و SSH در فایل محلی `native/config.json` می‌ماند و در مخزن و بستهٔ انتشار قرار نمی‌گیرد. بسته ZIP هیچ تاریخچهٔ Git ندارد.

## به‌روزرسانی از نسخه قبلی

Chrome را ببندید، `scripts/install.ps1 -SkipLaunch` را دوباره اجرا کنید، سپس افزونه و صفحه ChatGPT را Reload کنید. اگر میزبان در حال اجرا باشد، نصب‌کننده فایل جدید را با پسوند `next.exe` نگه می‌دارد و باید پس از بستن Chrome نصب را تکرار کنید.
